Commandes

Clavier + souris

  • Z Q S D / W A S D / flèches — se déplacer
  • Souris — viser (gauche/droite et haut/bas) · Clic gauche / Ctrl — tirer
  • Espace / E / Clic droit — ouvrir, pousser, activer
  • 1…5 / Molette — changer d'arme
  • Maj — courir · Alt + flèches — pas latéral
  • F — allumer / éteindre la lampe torche (elle se recharge toute seule quand elle est éteinte)
  • Tab / M — carte · Échap / P — pause

Écran tactile

  • Pouce gauche — joystick de déplacement
  • Glisser à droite — tourner la vue et regarder en haut / en bas
  • FEU — maintenir pour tirer (glisser pour viser)
  • USE — ouvrir / activer · ARME ▸ — arme suivante · ☀ — lampe

Manette

  • Sticks — bouger / viser · RT tirer · A utiliser · Y lampe · LB/RB armes · Start pause

Astuce : certains murs sonnent creux… Poussez-les. Éteignez la lampe de temps en temps : elle se recharge seule.
